# 首都高ぐるり

首都高速の**距離別料金制**(料金は入口↔出口の最短経路距離で決まり、実走行経路や周回数に
依存しない)を活かして、**最低料金で楽しめる周回コース**を提案する iOS 最適化 PWA。

## 使い方

静的サイトなのでそのまま配信するだけで動きます。

```sh
python3 -m http.server 8080
# → http://localhost:8080 を iPhone の Safari で開き「ホーム画面に追加」
```

- ホーム画面追加でフルスクリーン起動(スタンドアロンPWA)
- Service Worker により2回目以降はオフライン(トンネル内圏外)でも動作

## 機能

- 7つの周回コース(C1一周 / C2大一周 / 大黒PAナイトクルーズ / レインボーブリッジ /
  グランドツアー110km / 平和島ゴジラルート / 代々木夕景)
- 車種別料金(普通車 / 軽・二輪)・深夜割引(0-4時 ETC 20%)の即時反映
- コスパ順(円/km)などの並べ替え、お気に入り(localStorage)
- コース詳細: SVGデフォルメ路線図(経路ハイライト)・ルート行程タイムライン・PA情報
- 料金の仕組み解説画面(計算式・現金車・料金改定予告・PA夜間閉鎖情報)
- 起動時の安全注意モーダル(運転中の操作禁止)

## 開発

依存ゼロ・ビルド工程ゼロ(バニラ HTML/CSS/JS, ES Modules)。

```sh
node test/toll.test.mjs   # 料金計算の単体テスト
```
